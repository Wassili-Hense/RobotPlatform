### I2C protocol
Slave address: 0x14

### Read from slave (fixed packet)

Slave returns one fixed-size packet of 8 bytes on every read transaction.
Multibyte values are little-endian.

Packet bytes:

- Byte0 = buttons[7:0]
  - bit0 - Button ON
  - bit1 - Button Fire
  - bit2 - Button UP
  - bit3 - Button DOWN
  - bit4 - Button BACK
  - bit5 - Button OK
  - bit6 - Button LUP
  - bit7 - Button LDN
- Byte1 = status/buttons[15:8]
  - bit0 - Button RUP
  - bit1 - Button RDN
  - bit2..3 - reserved, 0
  - bit4 - USB connected (1 -> connected, 0 -> not connected)
  - bit5 - reserved, 0
  - bit6 - LCD backlight state (1 -> on, 0 -> off)
  - bit7 - reserved, 0
- Byte2 = ADC X low byte
- Byte3 = ADC X high/status byte
  - bits[3:0] = ADC X bits[11:8]
  - bits[6:4] = reserved, 0
  - bit7 = ADC X changed flag
  - master reconstructs ADC X as: `((Byte3 & 0x0F) << 8) | Byte2`
  - changed flag: `(Byte3 & 0x80) != 0`
- Byte4 = ADC Y low byte
- Byte5 = ADC Y high/status byte
  - bits[3:0] = ADC Y bits[11:8]
  - bits[6:4] = reserved, 0
  - bit7 = ADC Y changed flag
  - master reconstructs ADC Y as: `((Byte5 & 0x0F) << 8) | Byte4`
  - changed flag: `(Byte5 & 0x80) != 0`
- Byte6 = ADC U low byte
- Byte7 = ADC U high/status byte
  - bits[3:0] = ADC U bits[11:8]
  - bits[6:4] = reserved, 0
  - bit7 = ADC U changed flag
  - master reconstructs ADC U as: `((Byte7 & 0x0F) << 8) | Byte6`
  - changed flag: `(Byte7 & 0x80) != 0`

Buttons bit = 1 means button pressed.

#### Write to slave

One command per I2C write transaction.
Maximum write length: 32 bytes.
Multibyte parameters are little-endian.

- BacklightTimeout(uint32 timeout_ms)
  - format: [0x03][t0][t1][t2][t3]

- BacklightBrightness(level)
  - level: 0..127
  - format: [0x04][level]

- Tone(divider, delay_ms)
  - divider = 1000000 / Hz
  - format: [0x07][divider_lo][divider_hi][delay_lo][delay_hi]

- Melody(melody)
  - melody: 1 - POWER_ON, 2 - CONNECTED, 3 - DISCONNECTED
  - format: [0x08][melody]

- PowerOff()
  - immediately disables PA11 (power latch)
  - format: [0x0F][0xAA]
